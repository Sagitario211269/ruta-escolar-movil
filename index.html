Control de abordaje

Los datos se guardan en este teléfono. Para empezar, importa un respaldo integral exportado desde el computador de coordinación.
No hay una base de datos cargada.

1. Recorrido

Solo días hábiles. No se permite registrar en fechas bloqueadas ni en recorridos cerrados.
Seleccione una ruta y fecha.
La cámara en vivo requiere que esta aplicación se abra desde una dirección HTTPS segura y que autorices el permiso. También puedes seleccionar una foto del carné para leer el QR sin conexión.
Seleccione una ruta para comenzar.

2. Pasajeros

Seleccione una ruta.
0 / 0

3. Entregar registros a coordinación

Exporta únicamente los estudiantes que abordaron en la ruta y fecha seleccionadas. El archivo se identifica con el nombre de la ruta y la fecha; envíalo a coordinación. No necesitas conexión a Internet para registrar abordajes.

No borres los datos de este teléfono hasta confirmar que coordinación recibió e importó el archivo.

Almacenamiento y privacidad

Los registros se guardan localmente en el navegador de este dispositivo. No se envían a un servidor. Si borras los datos del navegador o desinstalas la aplicación, puedes perderlos; exporta respaldos con frecuencia.
